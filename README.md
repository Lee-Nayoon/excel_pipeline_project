### 1. 분석 개요

* **목적**: 수작업으로 진행되던 지점별 판매 데이터 수집·정제·요약 및 차트 생성을 백엔드 파이프라인으로 자동화하여 데이터 정확성 확보 및 보고서 작성 시간 단축
* **사용 도구**: Python (Pandas, openpyxl, Logging, Try-Except)
* **산출물**: 
  1. 지점별 노이즈 패턴을 포함한 약 360여 건의 가상 엑셀 데이터셋 생성 스크립트 (`create_dummy_data.py`)
  2. 정제 및 데이터 통합 완료된 CSV 데이터셋 (`cleaned_merged_data.csv`)
  3. 서식 및 막대차트(지점명·매출액 라벨 포함)가 자동 생성된 경영진 제출용 엑셀 보고서 (`전국_지점별_판매_실적_보고서.xlsx`)
  4. 실시간 실행 상태 및 예외 추적을 위한 파일 로그 (`app.log`)

---

### 2. 데이터셋 개요

* **데이터 소스**: 현업 데이터 수집 환경을 시뮬레이션하기 위한 자체 맞춤형 가상 데이터셋 구축
* **데이터셋 규모 및 구조**: 총 5개 지점별 독립 엑셀 파일, 약 360여 건의 데이터
* **지점별 의도적 노이즈 및 예외 데이터 설계**:
  1. **서울점 (100건)**: `' 지점명 '`, `' 상품명 '` 등 컬럼명 앞뒤에 공백 포함
  2. **부산점 (80건)**: 수량 및 단가에 숫자 외 쉼표(`,`), `'개'`, `'원'` 등 텍스트 혼용
  3. **인천점 (70건)**: 수량 및 단가 컬럼에 무작위 결측값(NaN) 15% 발생
  4. **대구점 (60건)**: 비표준 컬럼명 사용 (`'지점'`, `'판매가'`)
  5. **울산점 (50건)**: 수량/단가 등 필수 컬럼 누락 (파이프라인 예외 감지 테스트용)
* **핵심 구현 모듈**: `create_dummy_data` (데이터 생성), `DataCleaner` (전처리), `ExcelReporter` (리포트/차트 자동화), `setup_logger` (로깅 모듈)

### 3. 파이프라인 구축 및 핵심 기술 과정

* **지점별 현실적 데이터 노이즈 시뮬레이터 개발 (`create_dummy_data.py`)**:
  1. NumPy와 Python `random` 모듈을 활용하여 30일 이내 임의 판매일자 및 전자제품 5종 (모니터, 키보드, 마우스, 노트북, 헤드셋) 단가 맵을 생성
  2. 문자열 혼용, 컬럼 공백, 비표준 컬럼명, 결측치, 필수 컬럼 누락 등 5가지 지점별 예외 케이스를 갖춘 테스트용 엑셀 데이터 5개를 자동 생성하도록 구축
* **다중 파일 자동 로드 및 이상 컬럼 대응**:
  1. `DataCleaner` 클래스를 통해 입력 디렉터리 내 다중 엑셀 파일 자동 수집
  2. 컬럼명 앞뒤 공백 제거 및 비표준 컬럼명 매핑 표준화 적용
* **데이터 정제 및 타입 정규화**:
  1. 정규표현식(Regex) 및 문자 정제 함수를 이용해 수량/단가 내 텍스트를 제거하고 숫자형 타입으로 정규화
  2. 결측치가 존재하는 행 정제 및 총매출액 계산 필드 자동 생성
* **예외 처리 및 파일 단위 에러 핸들링**:
  1. 필수 컬럼이 누락된 파일(예: 울산점) 탐지 시 파이프라인 전체 중단 대신 해당 파일 스킵 후 경고 로그(`logger.warning`)를 남기는 구조 설계
* **동적 셀 스타일링 및 열 너비 자동 조절**:
  1. `openpyxl`로 상세 시트와 요약 시트를 분리 구성
  2. 헤더, 테두리, 금액 천 단위 콤마 서식 일괄 적용
  3. 유니코드 가중치 계산식을 도입해 한글/영문/숫자 혼용 시에도 컬럼 너비가 잘리지 않는 자동 맞춤 알고리즘 구현
* **시각화 차트 자동 생성 및 동적 부착**:
  1. 요약 데이터의 행 수를 파악하여 `Reference` 객체로 데이터 영역과 지점명 범주(Category) 영역을 동적으로 할당
  2. `BarChart` 객체를 생성하여 세로 막대 형태 지정, 차트 제목, 차트 크기 및 기본 스타일 자동 설정 적용
  3. `DataLabelList`를 생성하여 막대 그래프 상단에 지점명과 매출 수치가 동시에 명확하게 표기되도록 구현
  4. 구성된 차트를 요약 시트 내 특정 앵커 위치(`D3`)에 자동 배치하여 보고서 오픈 시 즉시 확인 가능하도록 구현

### 4. 트러블 슈팅 및 문제 해결 과정

#### [Issue 1] 수집 데이터 생성 시 상품명-단가 불일치 및 매칭 오류 방지
* **현상 및 문제점**: 테스트 데이터 생성 초기 단계에서 상품명과 단가를 각각 별도로 `random.choice()` 추출할 경우, 동일한 상품명에 서로 다른 단가가 매핑되거나 단가 정보가 오작동하는 불일치 문제 발생
* **해결 방안**: 매 행 생성 시 `random.choice(products)`를 통해 `(상품명, 단가)` 튜플 1개를 무작위로 먼저 추출한 후, 해당 튜플 요소에서 `item[0]`(상품명)과 `item[1]`(단가)을 각각 분리 추출하여 데이터프레임 각 컬럼에 할당함. 이를 통해 무작위 데이터 생성 환경에서도 상품명과 단가의 1:1 결합 무결성을 완벽히 보장.

#### [Issue 2] 필수 컬럼 누락 파일 처리 방식 및 데이터 품질 관리 정책 변경
* **현상 및 문제점**: 필수 컬럼이 누락된 파일(예: 울산점) 탐지 시, 초기에는 빈 컬럼을 자동 생성하여 결측값으로 채우는 방식을 검토했으나, 핵심 요약 데이터 분석 시 데이터 전반의 품질을 저하시키는 부작용이 우려됨.
* **해결 방안**: 분석 신뢰도를 해치는 무분별한 결측치 채우기 대신, 필수 컬럼 누락 감지 시 해당 파일을 파이프라인 집계 대상에서 안전하게 제외하고 `logger.warning()`으로 파일명을 명시하도록 예외 처리 방식을 개선함.

#### [Issue 3] 단가 결측치 보정 로직 고도화 (단순 0원 처리 -> 최빈값 기반 대체 보정)
* **현상 및 문제점**: 수량/단가 컬럼 내 결측치 정제 시 단순 `0`으로 채울 경우, 전체 총매출 실적이 왜곡되는 문제가 발생함.
* **해결 방안**: 단가 누락 건 발생 시 단순 0원 처리가 아닌, 해당 상품의 최빈값(Mode) 기반의 대체 보정 기법을 적용함. 이를 통해 매출 집계 누락을 예방하고 실제 매출액에 가장 가까운 정밀한 데이터 집합을 복원함.

#### [Issue 4] openpyxl 차트 범례 중복 및 라벨 누락 현상
* **현상 및 문제점**: 기본 `BarChart` 부착 시 막대 위에 지점명/매출액 정보가 나타나지 않고 단일 데이터 시리즈임에도 의미 없는 범례가 공간을 차지하여 가독성이 저하됨.
* **해결 방안**: `DataLabelList` 객체를 선언하여 지점명/매출액을 표시하고, 단일 시리즈 특성에 맞춰 범례(`chart.legend = None`)를 제거해 시각적 직관성을 극대화함.

#### [Issue 5] 한글/영문 혼용 시 엑셀 컬럼 너비 잘림 현상
* **현상 및 문제점**: Python 기본 `len()` 함수 기준으로 열 너비를 산출할 경우, 글자 폭이 넓은 한글 텍스트가 엑셀에서 완전히 표시되지 못하고 잘리는 현상이 발생함.
* **해결 방안**: 유니코드 가중치 계산 알고리즘을 도입하여 한글/전각 문자의 개수만큼 너비를 추가 계산(글자당 너비 2 적용)함으로써 컬럼에 입력된 문자열 길이에 따라 너비가 동적으로 최적화되도록 개선함.

### 5. 결론 및 프로젝트 회고

#### 비즈니스 성과 및 기대 효과
1. **업무 공수 절감**: 기존에 지점별 파일 수집, 전처리, 엑셀 정렬, 서식 적용, 차트 생성까지 수작업으로 매월 수 시간 소요되던 작업을 코드 한 번 실행으로 완료되도록 100% 자동화하여 작업 시간을 단 몇 초 단위로 단축함.
2. **데이터 신뢰성 제고 및 휴먼 에러 차단**: 인적 가공 과정에서 발생할 수 있는 계산 실수나 서식 오적용을 방지하고, 로깅 시스템을 통해 데이터 정제 과정의 추적성을 완전 확보함.

#### 기술적으로 배운 점 및 핵심 성과
1. **비즈니스 로직 중심의 정밀한 데이터 전처리**: 
   * 단순 결측치 삭제나 0원 채우기로 인한 실적 왜곡 리스크를 파악하고, 상품 마스터 데이터 매핑 및 최빈값 기반 단가 복원 기법을 적용하여 매출 데이터의 정밀도를 극대화함.
   * 분석 데이터 품질을 해치는 필수 컬럼 누락 파일은 무리하게 결측치를 채우기보다 선별적으로 제외하고 로그를 남기는 등 실무 운영 환경에 적합한 데이터 품질 관리 체계를 구축함.
2. **End-to-End 파이프라인 및 고급 시각화 구축**:
   * 데이터 생성 스크립트부터 전처리, `openpyxl`을 활용한 고급 엑셀 보고서 서식 및 동적 차트 자동 생성까지 전체 파이프라인을 객체지향 모듈 구조로 구현함.

#### 프로젝트 총평
1. 본 프로젝트는 단순한 코드 작성을 넘어, 현업 데이터 수집 환경의 현실적인 한계를 직접 시뮬레이션하고 데이터 품질과 비즈니스 정밀도까지 고민하여 설계한 종합 파이프라인입니다.
2. 이러한 접근 방식을 통해 실제 데이터 분석 업무에서 요구되는 데이터 무결성 확보 역량과 데이터 백엔드 자동화 역량을 입증했습니다.
